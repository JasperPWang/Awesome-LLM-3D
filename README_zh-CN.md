## 🏠 About 关于
Here is a curated list of papers about 3D-Related Tasks empowered by Large Language Models (LLMs).<br>这里整理了由大语言模型（LLM）赋能的三维相关任务论文。
It contains various tasks including 3D understanding, reasoning, generation, and embodied agents. Also, we include other Foundation Models (CLIP, SAM) for the whole picture of this area.<br>涵盖三维理解、三维推理、三维生成和具身智能体等任务，同时收录其他基础模型（CLIP、SAM），以完整呈现这一领域。

This is an active repository, you can watch for following the latest advances. If you find it useful, please kindly star ⭐ this repo and [cite](#citation) the paper.<br>这是一个持续更新的仓库，欢迎关注最新进展。如果觉得有帮助，欢迎为仓库加 ⭐ 并[引用](#citation)论文。
